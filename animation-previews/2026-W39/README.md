# Tora & the Gangz — W39 animation previews

คุณเป้เลือก 3 เรื่องจาก `Dialogue/tora-selected-2026-W39.json`: 01 เจ้าป่าประจำระเบียง, 02 ไลฟ์สายฝนจากระเบียง, 09 ท้าประลองปีนกิ่งไม้เตี้ย. ภาพใน `keyframes/` เป็นภาพตั้งต้นที่ดัดแปลงจากตัวละครต้นฉบับใน `pic/` สำหรับทดสอบการขยับภาพ ไม่ใช่คลิปอนุมัติสำหรับ YouTube.

- 01: โทระประกาศตัวบนขอบกระถางเตี้ย → วิ่งข้ามกล่องพัสดุเตี้ยแล้วลื่น → มินนี่ยกคะแนน 2/10 → โทระขึ้นกล่องเตี้ยกว่าแล้วประกาศอีกครั้ง
- 02: ตามคอมเมนต์คุณเป้ ให้เริ่ม medium shot มินนี่ใต้ชายคาถือกิ่งไม้แทนไมค์ ปากขยับและชี้ออกไป → wide shot ฝนเริ่มตก → close-up เท้าแตะหยดน้ำ → ป๊อบบี้สะกิดจนมินนี่กระโดดออกไป → เปียกแต่ยิ้มภูมิใจ
- 09: ตามคอมเมนต์คุณเป้ เปิด wide shot สวนหมู่บ้าน โทระชี้ไปกิ่งไม้เตี้ยท้าประลอง → ทั้งคู่ปีนกิ่งใกล้พื้น → โทระรีบวิ่งไปปลายกิ่งเล็กที่โอนเอนแล้วลงพื้นอย่างปลอดภัย → คู่ปรับยืนบนโคนกิ่งหนาที่มั่นคง → มินนี่ให้ชนะ โทระปรบมือ. แก้จากบทเดิมที่กิ่งรับน้ำหนักโทระไม่ไหวแต่รับหมาตัวใหญ่กว่าได้.

ทุกตอนเป็น silent comedy ไม่มีบทพูด; ปากขยับเป็นภาษากายเท่านั้น ไม่ใช้ Botnoi Voice. คลิปตัวอย่างใช้เสียงบรรยากาศ/เอฟเฟกต์จากการตัดต่อภายหลัง และยังไม่อัปโหลด YouTube.
